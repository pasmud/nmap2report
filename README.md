# nmap2report

Convert nmap XML scans into self-contained HTML, Markdown, and CSV reports.

`nmap2report` is a small, dependency-free Python tool that turns the XML
output of an nmap scan into readable reports. It focuses on clear presentation
of hosts, services, scripts, and a documented heuristic risk overview. It is
not a vulnerability scanner.

## Status

The project is under active development. This scaffold contains the package
layout, build metadata, and license. Usage documentation will be added as the
parser and report renderers land.
